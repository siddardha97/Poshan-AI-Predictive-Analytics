# Demo dataset dictionary

- `state`, `district`: fictional demo grouping labels based on common Indian geography names.
- `stunting_pct`, `wasting_pct`, `underweight_pct`: randomly generated values for interface testing, not measured estimates.
- `population_under5_est`: random placeholder count, not official population.
- `data_source`: explicitly marks all rows as synthetic.
- `period`: synthetic demo label.

Replace this file only with properly cited public data after reviewing its metadata and license.
